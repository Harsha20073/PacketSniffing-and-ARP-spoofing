# NetSentinel – Packet Sniffer & ARP Spoofing Detection Tool

## Overview

NetSentinel is a Python-based cybersecurity project developed on Kali Linux using Scapy. It captures and analyzes live network traffic in real time while monitoring for potential ARP spoofing attacks. The project is designed as a learning tool for network security and as an internship portfolio project, demonstrating practical skills in packet analysis, protocol inspection, and network monitoring.

## Features

* Live packet capture
* Network interface selection
* TCP packet analysis
* UDP packet analysis
* ICMP packet analysis
* ARP packet analysis
* Basic ARP spoofing detection
* HTTP/HTTPS traffic identification
* DNS packet detection
* Source and destination IP address monitoring
* Source and destination MAC address monitoring
* Source and destination port detection
* Packet statistics and counters
* CSV packet logging
* Session report generation
* Protocol filtering
* Command-line interface support
* Modular Python project structure

## Technologies Used
